# Moodbeats

Moodbeats is a full-stack web app that recommends Spotify playlists based on a user’s mood. Users can browse playlists, open them in Spotify, save playlists, rename them, and delete them.

## Features

- Mood-based Spotify playlist search
- Save playlists to database
- Rename saved playlists
- Delete saved playlists
- Open playlists directly in Spotify
- Responsive UI

## Tech Stack

Frontend:
- React
- Vite
- CSS

Backend:
- Node.js
- Express.js
- PostgreSQL

API:
- Spotify Web API

Deployment:
- Render

## CRUD Operations

- Create → Save playlists
- Read → View playlists
- Update → Rename playlists
- Delete → Remove playlists
